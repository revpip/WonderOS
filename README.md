# WonderOS

**The editorial operating system.**

> Build knowledge once. Connect it forever. Publish it everywhere.

WonderOS is a professional workspace for people who build knowledge. It stores canonical entities, relationships, claims, sources and editorial assets independently of any publishing channel, then projects trusted work to WordPress and future destinations.

## Genesis

WonderOS is currently in its Genesis phase. The first vertical slice will take one canonical entity—**Barn Owl**—through research, provenance, commissioning, drafting, review and safe WordPress publication.

## Core principles

- Knowledge exists once.
- Provenance is sacred.
- AI proposes; editors decide.
- Assets are reusable.
- Publishing channels are projections.
- Every contribution should make the whole system more valuable.

## Status

Foundation work is beginning. Architecture, contribution standards and the initial engineering backlog will be developed in version-controlled documents inside this repository.
